# Admission Hub v0.16.1 — Real-device High3 + Official Evidence Repair

v0.16.1은 v0.16.0을 실제 Galaxy에서 실행한 화면 녹화와 대시보드 결과를 기준으로 수정한 패치입니다.

## 확인된 실기기 문제

1. 학생부 53과목이 정상 저장되어도 기존 프로필에는 `documentCompletenessVerified` 필드가 없어서 대학 환산이 계속 보류될 수 있었습니다.
2. 진학사 로그인 URL이 그대로인 상태에서 화면 상단 상품 탭이 `고3·N수`에서 `고1·2`로 실제 전환되었습니다. 따라서 URL 경로만 차단하는 방식으로는 로그인 문제를 해결할 수 없었습니다.
3. 정상 어디가 구조 결합으로는 일부 지원안의 과거 입결이 누락되었고, 실제 공식 자료에서 수치가 비공개이거나 신설학과라 전년도 수치 자체가 없는 경우도 모두 `미확인`으로 보였습니다.

## 학생부 → 대학 환산

공식 산식 실행 시 저장된 플래그만 보지 않고 현재 학생부 프로필의 구조를 다시 검사합니다.

- 1-1, 1-2, 2-1, 2-2, 3-1 학기 범위
- 충분한 실제 과목 행
- 과목명 존재
- 이수단위/학점 존재
- 없는 등급이나 과목은 생성하지 않음

따라서 v0.15/v0.16에서 이미 저장한 학생부도 다시 업로드하지 않고 구조가 충족되면 환산 계산 대상으로 사용할 수 있습니다.

정량 공식 산식이 없는 학생부종합Ⅱ와 아직 공식 산식을 안전하게 식별하지 못한 지원안은 계속 HOLD입니다.

## 진학사 고3·N수 전용 로그인 fence

진학사 정보 수집 중에는 고1·2 로그인 컨텍스트를 표시하거나 선택하지 않는 방식으로 강화합니다.

1. URL fence: `/jh/high1/`, `/jh/high2/`, `/jh/high12/` 직접 경로뿐 아니라 공용 로그인 URL의 query/fragment에 인코딩된 lower-grade return 경로도 탐색 전에 차단합니다.
2. 로그인 화면 shield: 수집/인증 중 공용 로그인 URL에 도착하면 WebView를 먼저 숨기고, DOM에서 고3·N수 또는 중립 통합 로그인 상태가 확인되기 전에는 로그인 화면을 표시하지 않습니다.
3. DOM fence: `고1·2` 제품 선택 요소는 숨기고 클릭을 차단합니다. lower-grade가 활성화됐거나 고3·N수 활성 상태가 확인되지 않으면 고3·N수를 선택한 뒤 다시 검증합니다.
4. Credential preflight: 저장 계정 자동 제출 직전에도 고1·2 선택 요소를 비활성화하고 고3·N수 컨텍스트가 확인된 뒤에만 자격정보 제출을 계속합니다.
5. Fail-closed: lower-grade 상태를 안전하게 해소하지 못한 동안에는 해당 로그인 화면을 노출하지 않고 재확인합니다.

수집 시작 시에는 로그인 URL을 먼저 강제로 여는 대신 고3 보호 경로의 인증 상태를 확인하는 기존 구조를 유지합니다. 진학사가 세션 만료로 공용 `/jh/member/login`으로 리다이렉트하는 경우 공용 로그인 자체는 사용할 수 있지만, 그 안의 고1·2 제품 컨텍스트에는 진입하지 않습니다. 비밀번호는 로그/JSON/GitHub로 내보내지 않습니다.

재인증 circuit breaker 최대 3회도 유지합니다. 즉 로그인 해결 시도를 하되 무한루프는 허용하지 않습니다.

## 공식 입결 fallback

정상 어디가 current-session 재스캔을 가장 먼저 사용합니다. 그래도 해당 지원안에 검증된 공식 입결이 없을 때만, 현재 선택 6장 중 정확히 식별 가능한 지원안에 대해 공식 게시자료 registry를 사용합니다.

등록된 공식 근거:

- 우송대학교 입학종합서비스 공식 2025 수시 결과: 철도차량시스템학과 학생부교과 면접
- 대입정보포털 어디가 국립한국교통대학교 공식 2025 결과: 철도차량시스템공학과 나비인재Ⅱ(현 학생부종합Ⅱ 명칭 변경 전)
- 대입정보포털 어디가 국립한밭대학교 공식 2025 결과: 자율전공학부 학생부교과(일반)
- 대입정보포털 어디가 국립한밭대학교 공식 2025 결과: 반도체시스템공학과 지역인재(교과) — 모집인원 3명으로 수치 비공개
- 우송대학교 공식 2025 결과표: 철도자율전공은 신설 모집단위로 전년도 수치형 입결 없음

`비공개`와 `신설로 전년도 수치 없음`은 숫자를 만들어 넣지 않고 대시보드에 명시적으로 표시합니다.

충남대 `건축`처럼 모집단위 identity가 건축학과/건축공학과 중 어느 것인지 확정되지 않은 항목은 fallback으로 임의 연결하지 않습니다.

## 출처 정책

- 어디가·대학 입학처 공식 게시물: 공식 기준/공식 과거 입결
- 진학사: 사용자 계정에서 실제 열람한 예측·분석

진학사 수치를 공식 입결로 승격하지 않습니다. `HOLD` 또는 `probabilityInferred=false`에서 합격확률을 생성하지 않습니다.

## 실기기 승인 조건

CI 통과 후에도 다음은 실제 Galaxy에서 다시 확인해야 합니다.

1. 학생부 재업로드 없이 지원 대학 환산이 다시 계산되는지
2. 진학사 정보 수집 단계에서 고1·2 로그인 화면/제품 컨텍스트가 표시되지 않는지
3. 공용 로그인 리다이렉트가 필요한 경우 고3·N수 또는 중립 통합 로그인 확인 후에만 화면이 표시되고 자동 로그인되는지
4. 자동 로그인 후 보호된 고3 페이지로 진입하는지
5. 공식 입결이 `숫자 / 공식 비공개 / 신설로 전년도 없음 / identity 확인 필요`로 구분되는지
6. 어디가와 진학사의 표시가 서로 섞이지 않는지

최종 검증은 고1·2 로그인 컨텍스트 차단과 마지막 모집단위 identity/dedupe 수정까지 포함한 정확한 브랜치 소스에서 다시 수행합니다.
