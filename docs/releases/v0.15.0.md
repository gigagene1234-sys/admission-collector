# Admission Hub v0.15.0 — Dual Auto + Official Score/Outcome Repair

v0.15.0은 v0.14.2 실기기 화면에서 확인된 자동화 퇴화를 복구하는 버전입니다. 정상 사용 경로는 `통합 자동수집 시작` 한 번이며, 수동 수집·로그인 진단 버튼은 실패 시 복구/진단용으로 남깁니다.

## 1. 어디가와 진학사를 한 자동 파이프라인으로 처리

- 시작 시 어디가·진학사 두 도메인의 기기 내부 세션 lease 복원을 함께 시도합니다.
- 진학사 로그인 상태가 불확실해도 **어디가의 공개 공식자료 수집을 막지 않습니다.**
- 먼저 어디가 공식 현재 기준과 과거 입결을 수집하고, 이어서 진학사 보호 경로 인증을 실제 서버 응답으로 확인합니다.
- 진학사 인증이 만료된 경우에만 로그인 화면을 감지하고 Android Keystore에 저장된 계정을 자동 입력합니다.
- 로그인 성공을 단순 폼 제출로 판정하지 않고 실제 진학사 보호 경로 재진입으로 검증한 뒤 미션 수집을 이어갑니다.
- 웹 페이지 자체는 하나의 주 WebView에서 안전하게 순차 탐색합니다. 따라서 두 사이트를 동시에 병렬 클릭하는 구조가 아니라, 사용자가 공급자를 전환하거나 별도 수집 버튼을 누르지 않는 **공급자 독립형 단일 자동 실행**입니다.

## 2. 대학 환산점수를 Excel 이후가 아니라 수집 파이프라인에서 자동 재계산

v0.14.2에는 공식 전형·모집단위 구성요소를 각각 확인해도 `identityBindingVerified`가 동일행 직접결합만 인정하는 문제가 있었습니다.

v0.15.0에서는:

- 동일 원서의 지원년도 공식 전형 구성요소와 모집단위 구성요소가 모두 확인되고,
- 앱에 이미 검증·고정된 해당 대학/전형 공식 산식이 실제로 계산에 성공한 경우,
- `scoringScopeBindingVerified`를 대학 환산점수의 검증 결합으로 인정합니다.

이 완화는 **현재년도 환산점수 산식에만 적용**합니다. 과거 입결은 계속 동일 전형 + 동일/동등 모집단위 + 공식 표 헤더 검증이 필요한 별도 엄격 규칙을 사용합니다.

현재 자동 정량 산식 범위는 기존과 동일하게 검증된 2027 우송대 교과면접/교과중심, 국립한밭대 지원 전형에 한정됩니다. 한국교통대 학생부종합Ⅱ처럼 정성 서류평가인 전형에는 가짜 정량 환산점수를 만들지 않습니다.

## 3. 공식 과거 입결은 학생부 입력 여부와 무관하게 자동 탐색·저장

v0.14.2에서는 공식 과거 입결 materializer가 사실상 학생부 Excel 저장 경로에 묶여 있어, 어디가에 과거 입결이 이미 수집되어도 Hub에는 `공식 입결 0/6`으로 남을 수 있었습니다.

v0.15.0에서는:

- 어디가 수집 종료 시 1차 공식 입결 re-index,
- 진학사 수집 후 canonical merge 완료 시 2차 공식 입결 re-index

를 자동 실행합니다. 학생부 프로필이 `NOT_IMPORTED`여도 공식 과거 입결의 탐색·구조 검증·저장은 진행됩니다.

과거 입결은 다음 조건을 모두 만족한 경우에만 원서별 공식값으로 저장합니다.

- 전형명 exact match
- 모집단위 exact 또는 suffix-equivalent match
- 동일 공식 표 또는 명시적 동일 표 구간
- 모집인원·경쟁률·50% cut·70% cut과 대학별환산/학생부등급 헤더 검증

대학 단위 공통값이나 다른 전형의 숫자를 원서 입결로 추정 승격하지 않습니다.

## 4. 학생부 XLS/XLSX 자동 인식 2단계

기존 인식기는 `학년`, `학기`, `과목`이 모두 열로 반복된 표에 강했습니다. 실제 학교 학생부 Excel처럼 학년·학기가 병합 셀/구간 제목으로 표시되는 파일은 workbook 자체는 열어도 과목행으로 만들지 못할 수 있었습니다.

v0.15.0은 두 경로를 자동으로 실행합니다.

1. 기존 strict-column 인식
2. `1학년`, `1학기`처럼 파일에 **명시된** 학년·학기 구간을 과목행에 안전하게 전달하는 Korean transcript section 인식

둘 다 성공하면 더 많은 정상 과목을 확보한 결과를 우선합니다. 학년·학기를 일반상식으로 추측하지 않으며, 파일에 명시된 열·병합·구간 표지만 사용합니다. 석차등급이 없는 진로선택 과목은 계속 빈칸/null로 보존합니다.

학생부가 모든 판단 대상 과목·학기를 포함하는지 여부는 파일 구조만으로 보장할 수 없으므로 `전체 학생부 확인` 체크는 자동으로 켜지 않습니다. 이 확인이 없어도 공식 과거 입결 수집은 진행되며, 개인 환산점수만 보수적으로 HOLD될 수 있습니다.

## 5. `공식 연결 0/6` 표시 분해

기존의 단일 `공식연결` 숫자가 다음 두 의미를 섞고 있었습니다.

- 지원년도 공식 전형/모집단위 구성요소 확인
- 같은 행/같은 표 구간에서 원서 전체가 직접 결합됨

v0.15.0은 화면에서 `공식 구성요소 X/6`과 `동일행 직접결합 Y/6`을 분리합니다. 직접결합이 0이라고 해서 어디가 공식자료 자체가 0이라는 뜻으로 표시하지 않습니다.

## 유지되는 안전 원칙

- 어디가 = 공식 현재/과거 기준값, 진학사 = 사용자 열람 기반 파생 분석/예측 자료로 분리합니다.
- `probabilityInferred=false`를 유지하며 합격확률을 임의 계산하지 않습니다.
- relation이 HOLD인 원서는 필요한 근거가 채워지기 전 합격 가능/안정·적정·소신 판정을 만들지 않습니다.
- 기존 6장 슬롯은 수집·Excel import·재계산 과정에서 임의 변경하지 않습니다.
- 계정정보는 기기 Android Keystore에만 암호화 저장하며 JSON·SQLite 입시자료·로그·GitHub Actions·Cloudflare로 내보내지 않습니다.

## 설치 후 실기기 검증 항목

CI가 확인하는 것은 소스 계약, 단위/회귀 테스트, APK 빌드, 동일 커밋 clean rebuild, 패키지/버전/서명입니다. 아래 실제 사이트 동작은 Galaxy 기기에서 최종 확인이 필요합니다.

1. 기존 앱을 삭제하지 않고 v0.15.0 업데이트 설치
2. `통합 자동수집 시작` 한 번으로 어디가 수집이 진학사 로그인 대기 없이 시작되는지 확인
3. 진학사 단계에서 세션이 유효하면 자동 진행하고, 만료 시 저장 계정 자동입력 또는 최초 1회 로그인만 요구하는지 확인
4. 학생부 실제 XLS/XLSX를 선택했을 때 과목행이 직접 편집 화면에 표시되는지 확인
5. 통합 종료 후 `공식 구성요소`, `공식 검증 환산`, `공식 입결` 수치가 새 근거에 따라 갱신되는지 확인

실제 파일/사이트 구조가 현재 파서의 검증 범위를 벗어난 경우에는 값을 추측하지 않고 해당 원서를 HOLD로 유지해야 합니다.
