Adds usable application review for the user's selected six, with reasons, missing evidence and conditions to recheck. No admission probabilities or unsupported safe/target/reach thresholds are generated.

- Local transcript entry and CSV/TSV/JSON import, preview before saving, duplicate and range validation. Missing grades remain missing. University conversions are separate from the transcript average.
- Per-application official-source input: own converted score, historical metric, year, scale, direction, maximum, formula and row excerpts. Comparisons are explicitly conditional on user-reviewed official sources; they are not automatically certified official calculations. A changed or incomplete transcript holds the comparison until rechecked.
- Eligibility, CSAT minimum, documents, multiple-application rules and Korea-time deadlines. Portfolio warnings include same-university applications and same-date interviews without assuming they are prohibited or impossible.
- Numeric Jinhak snapshots promoted only after re-verifying the exact single-card identity prefix and literal numbers. Predictions never overwrite official historical outcomes or independently verified conversions.
- Streaming export includes the score profile, score/decision evidence, review dashboard and exporter metadata. Original collection version is preserved separately.
- SQLite v10 adds review inputs and review history. Existing data and user-owned slots are preserved. Score summaries cover only selected applications.
- Manual login when required. Removes the obsolete custom encrypted credential/session copies and automatic credential submission. Native WebView sessions and protected-core auth proof, mission recovery, hard leases, local rebind and same-card protections remain.
- Wide layout keeps the 236dp minimum and three columns; cards and the overall screen can expand and scroll.

Install over the existing app. Do not uninstall or clear app data. A full 27-candidate crawl is not required to use the review tools.

The release workflow checks all unit tests, cumulative invariants, additive migration preservation, APK metadata and stable signer, then cleanly rebuilds and retests the exact source commit before publishing. Galaxy Tab acceptance of this new release remains a separate user-device check.
