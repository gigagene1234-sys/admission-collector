# Admission Hub v0.14.2 — One-Step Transcript + Auto Login

## 변경 목적

v0.14.1 실사용 내보내기에서 다음 문제가 확인되었습니다.

- 학생부 Excel 파일을 읽은 뒤 별도 확인창이 중심이 되어 실제 인식된 과목 입력을 검토·수정하기 어려웠습니다.
- 학생부 저장이 완료되지 않으면 대학별 공식 환산과 입결 재분석도 실행되지 않았습니다.
- 진학사 통합수집 완료 기준에 `university-result`가 빠져 있어 예측·모의지원·실제합격·성적분석은 수집했지만 대학/입시결과 계열 자료가 0건인 상태에서도 core complete가 될 수 있었습니다.
- 이전 보안 패치에서 자체 로그인정보 저장을 제거하면서, 로그인 화면 재진입 시 자동 로그인 경로가 사실상 수동 로그인으로 약화되었습니다.

## 학생부 Excel: 한 화면에서 분석 → 수정 → 저장 → 대학분석

- `.xls`와 `.xlsx`를 모두 지원합니다.
- 파일을 선택하면 시트/헤더/열을 자동 분석합니다.
- 자동 인식된 과목을 가로 스크롤 표로 즉시 표시합니다.
- 각 행의 학년·학기·교과·과목·석차등급·학점·성취도를 같은 화면에서 직접 수정할 수 있습니다.
- 잘못 인식된 행은 삭제하고 과목을 직접 추가할 수 있습니다.
- 자동 열 연결은 기본적으로 접어 두고 필요할 때만 수정할 수 있습니다.
- `현재 입력 다시 분석`으로 저장 전에 과목 수, 등급 과목 수, 등급 없는 과목 수, 학점 누락, 자체 가중평균을 바로 다시 계산합니다.
- 성공한 Excel 가져오기에 별도의 `저장 전 결과` 팝업을 사용하지 않습니다.
- `저장 + 6장 대학환산 · 공식입결 분석` 한 번으로 학생부 저장, canonical 재연결, 공식 산식 계산, 공식 입결 재연결을 실행하고 결과를 같은 화면 아래에 표시합니다.
- 등급이 비어 있는 진로선택 과목은 0등급으로 바꾸지 않습니다.
- Excel 수식은 실행하지 않고 파일에 저장된 캐시값만 읽습니다.

## 자동 로그인 복원

- 어디가/진학사 로그인 정보를 사용자가 한 번 입력하면 선택적으로 기기에 저장할 수 있습니다.
- 저장할 경우 AndroidKeyStore AES-GCM 키로 암호화합니다.
- 저장을 원하지 않으면 현재 앱 실행 중 메모리에서만 사용할 수 있습니다.
- 로그인 화면을 실제 DOM에서 확인한 경우에만 저장된 아이디/비밀번호를 해당 로그인 폼에 입력하고 제출합니다.
- 로그인 제출 후 기존 보호경로/세션 확인 로직으로 실제 인증 성공을 다시 검증합니다.
- 자동 로그인은 최대 제한 재시도를 적용하고 실패하면 사용자가 저장정보를 수정하거나 공식 사이트에서 직접 로그인할 수 있습니다.
- 저장된 로그인 정보 삭제 기능을 제공합니다.
- 아이디·비밀번호는 SQLite 입시자료, 통합 export, 진단 로그, Cloudflare 작업 또는 GitHub에 포함하지 않습니다.
- WebView의 기존 로그인 쿠키는 Android WebView 자체 저장소를 계속 사용합니다.

### v0.14.1에서 업데이트하는 경우

v0.14.1은 자체 credential copy를 의도적으로 제거했던 버전이므로, **v0.14.2 설치 후 최초 한 번은 어디가/진학사 로그인 정보를 다시 입력해야 할 수 있습니다.** 이후 `이 기기에 암호화 저장하고 다음부터 자동 로그인`을 선택하면 자동 로그인을 사용할 수 있습니다.

## 통합 자료 수집 강화

v0.14.2의 진학사 application core lane은 다음 6개입니다.

1. saved-application
2. current-prediction
3. mock-support
4. actual-admit
5. score-analysis
6. university-result

`university-result`가 빠진 상태에서는 더 이상 정상 core complete로 종료하지 않습니다. `strategy`는 편집/전략성 참고자료이므로 필수 종료 조건으로 강제하지 않습니다.

기존의 동일 원서 컨텍스트, target ledger, renderer 복구, 로그인 복구, process-resume 및 로컬 체크포인트는 유지합니다.

## 대학 환산 / 입결 원칙

- 우송대·국립한밭대의 이미 검증된 자동 산식 범위는 유지합니다.
- 국립한국교통대 학생부종합Ⅱ처럼 정성평가인 전형은 학생부 등급만으로 임의 환산하지 않습니다.
- 공식 입결은 같은 모집단위·전형·지표 척도 연결이 검증될 때만 직접 비교합니다.
- 학생부 저장이나 공식자료 재분석은 사용자가 선택한 6장 슬롯을 수정·재정렬하지 않습니다.

## 데이터/보안 보존

- 앱 데이터베이스 버전은 10을 유지합니다.
- 기존 학생부, 6장 선택 슬롯, 어디가/진학사 수집자료를 삭제하는 마이그레이션은 없습니다.
- 기존 안정 APK 서명을 유지해 v0.14.1 위에 업데이트 설치할 수 있도록 검증합니다.
- 앱을 삭제하면 Android 앱 로컬 데이터가 제거될 수 있으므로 기존 앱을 삭제하지 않고 업데이트 설치해야 합니다.
