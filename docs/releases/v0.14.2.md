# Admission Hub v0.14.2 — Unified Auto Flow

## 핵심 변경

v0.14.1에서 확인된 두 가지 사용성 회귀를 수정합니다.

### 1. 자동 로그인 복원

- 기존 WebView 로그인 세션을 우선 재사용합니다.
- 세션이 만료되어 실제 로그인 폼이 감지된 경우에만 저장 계정을 자동 입력합니다.
- 사용자가 자동 로그인을 선택하면 아이디·비밀번호는 Android Keystore AES/GCM 키로 기기 내부에서 암호화합니다.
- 저장 계정은 export JSON, SQLite 입시자료, 로그, Cloudflare/GitHub 작업, URL에 포함하지 않습니다.
- 자동 로그인 제출 이후에도 실제 보호 페이지 인증 성공을 확인한 뒤 수집을 재개합니다.
- 사용자는 언제든 저장 계정을 삭제하고 직접 로그인 방식으로 돌아갈 수 있습니다.

### 2. 학생부 Excel 분석과 입력을 한 화면으로 통합

- XLS와 XLSX를 모두 지원합니다.
- 파일을 선택하면 여러 시트와 헤더 후보를 자동 분석해 가장 유효한 학생부 표를 선택합니다.
- 인식된 과목은 바로 편집 가능한 입력 행으로 표시됩니다.
- 학년, 학기, 교과, 과목, 석차등급, 학점/이수단위, 성취도를 같은 화면에서 수정할 수 있습니다.
- 정상 자동 인식 경로에서는 별도 열 연결/결과 확인 팝업을 거치지 않습니다.
- 자동 인식이 실패한 파일만 기존 고급 시트/열 연결 화면으로 이동할 수 있습니다.
- `저장 + 6장 통합 분석` 한 번으로 학생부 저장, canonical 재결합, 가능한 대학별 공식 환산 재계산을 수행합니다.
- 빈 석차등급은 0으로 변경하지 않습니다.
- Excel 수식은 실행하지 않고 파일에 저장된 값만 사용합니다.

### 3. 진학사 통합 수집 범위 복원

v0.14.1 export에서 저장지원, 합격예측, 모의지원, 실제합격자, 성적분석은 모두 채워졌지만 대학별 입시결과와 전략 lane이 비어 있는 상태가 확인되었습니다.

v0.14.2에서는:

- `university-result`를 원서별 필수 통합 수집 lane으로 복원합니다.
- 입시전략/입시지식 read-only 경로를 기본 수시 탐색에서 더 이상 차단하지 않습니다.
- 기존 동일 원서 바인딩 원칙과 어디가 공식자료 우선 원칙은 유지합니다.
- 진학사 예측자료와 공식 과거 입결은 서로 다른 근거 유형으로 계속 분리합니다.

## 유지되는 안전 원칙

- 기존 6장 슬롯은 학생부 가져오기나 수집 과정에서 임의 변경하지 않습니다.
- 어디가의 대학 단위 공통자료를 특정 원서 입결로 임의 승격하지 않습니다.
- 한국교통대 학생부종합Ⅱ처럼 정성평가 전형에는 가짜 정량 환산점수를 만들지 않습니다.
- 계정정보는 백그라운드 서버로 보내지 않습니다. 자동 로그인은 Android 기기 내부에서만 수행됩니다.
- 백그라운드 GitHub Actions는 소스 검증, 테스트, APK 빌드와 서명 검증만 수행합니다.

## 설치 후 확인

1. 기존 앱을 삭제하지 않고 업데이트 설치합니다.
2. 최초 자동 로그인 사용 시 어디가/진학사 계정을 한 번 저장하거나 직접 로그인합니다.
3. 이후 앱 재실행 및 통합 수집 시 기존 WebView 세션이 우선 재사용되는지 확인합니다.
4. `내 성적` → `Excel 자동 분석 · 바로 입력`에서 실제 학생부 XLS/XLSX를 선택합니다.
5. 인식된 과목이 같은 화면에 표시되고 수정 가능한지 확인합니다.
6. `저장 + 6장 통합 분석` 후 대학별 공식 환산 및 입결 연결 수가 갱신되는지 확인합니다.
7. 진학사 수집 결과에서 `university-result`가 원서별로 채워지는지 확인합니다.

실제 기기에서 로그인 사이트의 추가 인증/보안키패드가 요구되는 경우 자동 제출이 제한될 수 있으며, 이 경우 앱은 직접 로그인을 요구해야 합니다.
