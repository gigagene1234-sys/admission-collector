## 안전 계약

- 외부 자료가 사용자 6장을 바꾸지 않는다.
- 대학/전형/모집단위/연도가 확인되지 않은 대학 단위 자료를 해당 원서의 공식 입결로 자동 승격하지 않는다.
- 과거 공식 입결과 진학사 예측은 별도 출처로 표시한다. 근거 없는 확률·안정/적정/소신 분류를 만들지 않는다.
- 대학 환산식 또는 척도·비교 방향이 미확인이면 성적 비교는 보류한다.
- XLSX의 빈 등급을 0으로 바꾸지 않는다. 학년·학기는 추측하거나 다른 학기로 옮기지 않는다. 수식은 실행하지 않는다.
- 비밀번호/쿠키/토큰/로그인 입력을 저장·수출하지 않는다. 기존 WebView 기본 세션만 사용한다.
