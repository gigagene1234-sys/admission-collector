현재 개발 구조

주 인터페이스: 웹
수집 상태·오류·진행률·후속 분석은 웹에서 확인합니다. 화면 수정과 배포도 APK 교체 없이 진행할 수 있습니다.
기기 실행기가 남는 이유
진학사/어디가 인증 세션과 자동 로그인은 제3자 사이트의 사용자 브라우저 컨텍스트가 필요하므로 Android WebView agent가 담당합니다. 계정정보는 웹 서버로 올리지 않습니다.
